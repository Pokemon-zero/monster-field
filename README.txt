# Monster Field - 무료 웹게임 1차 버전

## 실행
`index.html`을 웹브라우저로 열면 바로 실행됩니다.

## 포함 기능
- 멤버 목록 / 개인 프로필
- 지도와 지역 선택
- 탐색 → 랜덤 몬스터 조우
- 몬스터볼 사용 및 보상
- 가방 / 아이템 사용
- 상점 / 구매 / 화폐 자동 계산
- 날짜 기준 오늘의 특별상품
- localStorage 자동 저장

## 무료 공개
GitHub 저장소를 만든 뒤 이 3개 파일을 올리고 Settings → Pages에서 배포하면 무료 웹사이트로 공개할 수 있습니다.
